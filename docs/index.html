Reboot Trace

Linux 跳板机异常重启取证系统：在有限磁盘空间内持续记录主机、用户与高资源进程证据，并通过一个 Vue 前端统一查看多个后端实例。

首页需求架构数据库接口前端部署

已确定的技术决策

采集与 API

Python、asyncio、FastAPI；采集与 HTTP 请求解耦。

持久化

每台受监控主机使用本地 SQLite，默认空间预算 50 MiB。

前端

Vue 单页应用，运行时配置多个后端并统一呈现。

部署

前后端分离镜像，项目分别提供 Dockerfile。

访问方式

浏览器跨域直连各主机 HTTPS Ingress；第一版无登录鉴权，使用精确 CORS 和受控网络边界。

命令保护

原始命令不落盘，只保存脱敏后最多 4096 UTF-8 字节及脱敏后摘要。

产品边界

系统记录可供人类分析的证据，不自动宣称重启根因。采集到的最后快照只代表最近一次成功提交的状态；硬断电、内核崩溃或严重调度阻塞可能造成一个或多个采样周期的证据缺口。

文档样式以 style.css 为源，通过 python3 docs/sync_styles.py 内嵌；提交前使用 python3 docs/sync_styles.py --check 防止页面样式漂移。
